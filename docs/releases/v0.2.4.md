Peeky 아이콘이 메뉴바에서 안 보일 때 알려 주는 버전이에요.

## 설치와 업데이트

- **0.2.2 이상을 쓰고 있다면**: 메뉴바 Peeky 아이콘 메뉴의 **새 버전 0.2.4 설치…**나 설정 → 업데이트의 **지금 확인**을 누르면 바로 설치돼요. 자동 설치가 켜져 있으면 Peeky를 쓰지 않을 때 알아서 바꿔 넣어요.
- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면 하루 안에 저절로 업데이트돼요. 아니면 아래 **Peeky-0.2.4.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.2.4.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 새 기능

- **아이콘이 가려졌을 때 안내**: Peeky 아이콘이 노치에 가려졌거나 메뉴바에 자리가 없어 안 보이면, 설정 창 맨 위에 알려 주고 단축키로 바를 여는 방법과 자리를 만드는 방법을 보여 줘요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 아이콘이 가려진 상태에서는 응용 프로그램 폴더에서 Peeky를 한 번 더 열면 설정 창이 떠요.

## English

Peeky now tells you when its menu bar icon can't be seen.

**Installing and updating**
- On 0.2.2 or later: click **Install Version 0.2.4…** in the Peeky menu bar menu or **Check Now** in Settings → Updates, and it installs right away. With automatic installs on, Peeky swaps itself in when you're not using it.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.2.4.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.2.4.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**New**
- **Hidden icon notice**: if the Peeky icon is behind the notch or there's no room for it in the menu bar, the top of the settings window says so and shows how to open the bar with the shortcut and how to make room.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
- While the icon is hidden, open Peeky again from Applications to bring up the settings window.
