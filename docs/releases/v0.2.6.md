## 설치와 업데이트

- **0.2.2 이상을 쓰고 있다면**: 설정 → 업데이트의 **지금 확인**을 누르면 바로 설치돼요. 메뉴바 아이콘이 안 보이면 응용 프로그램 폴더에서 Peeky를 한 번 더 열어 설정 창을 띄우세요. 자동 설치가 켜져 있으면 Peeky를 쓰지 않을 때 알아서 바꿔 넣어요.
- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면 하루 안에 저절로 업데이트돼요. 아니면 아래 **Peeky-0.2.6.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.2.6.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 바뀐 점

- 메뉴바의 ‹ › 버튼이나 구분선(╱)을 오른쪽 클릭해도 Peeky 메뉴가 떠요. 그룹 열기, 숨긴 항목 펼치기/숨기기, 설정, **Peeky 종료**가 있어요. 그룹 아이콘이 가려져 있어도 여기서 끌 수 있어요.

## English

The ‹ › button and the divider now have the right-click menu too.

**Installing and updating**
- On 0.2.2 or later: click **Check Now** in Settings → Updates and it installs right away. If you can't see the menu bar icon, open Peeky again from Applications to bring up the settings window. With automatic installs on, Peeky swaps itself in when you're not using it.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.2.6.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.2.6.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**Changes**
- Right-clicking the ‹ › button or the divider (╱) in the menu bar opens the Peeky menu: open a group, show or hide hidden items, settings, and **Quit Peeky**. You can quit even when the group icons are hidden.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
