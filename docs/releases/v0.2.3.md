## English

A tidier bar, and updates that install themselves.

**Installing and updating**
- On 0.2.2: click **Install Version 0.2.3…** in the Peeky menu bar menu or **Check Now** in Settings → Updates, and it installs right away.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.2.3.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.2.3.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**New**
- **Automatic updates**: **Install new versions automatically** is now on by default. When you're not using Peeky, it downloads the new version, swaps it in and relaunches.

**Changes**
- The settings (⚙) button in the bar now sits in the last slot right after the icons instead of a separate column. With several rows, it's at the end of the last row.
- **Check for Updates…** and **Install Version X…** now install right away without asking.
- A window appears only when Peeky can't install in-app (automatic installs off, a location it can't replace, or an unsigned release).

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
