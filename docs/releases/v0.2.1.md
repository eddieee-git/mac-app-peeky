## 설치와 업데이트

- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면(0.1.0의 기본) 하루 안에 저절로 업데이트돼요. 꺼 두었다면 아래 **Peeky-0.2.1.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.2.1.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 다음 버전부터는 메뉴바 메뉴의 **새 버전 X 설치…**나 설정 → 업데이트의 **지금 확인**으로 받아요.

## 새 기능

- **메뉴바에서 숨기기**: 설정 → 메뉴바 정리에서 켜면 구분선(╱)이 생겨요. ⌘를 누른 채 아이콘을 구분선 왼쪽으로 옮기면 메뉴바에서 사라지고 Peeky 바에서만 보여요. 바에서 누르면 잠깐 펼쳐서 메뉴를 열고, 닫으면 다시 숨겨요.
- **끌어서 순서 바꾸기**: 바 안의 아이콘을 끌어 원하는 순서로 놓아요. 설정의 **순서 초기화**로 되돌려요.
- **노치에 마우스 올리기**: 켜 두면 노치에 마우스를 잠깐 올리기만 해도 첫 그룹 바가 열려요(기본 끔).
- **그룹마다 따로**: 그룹 옆 ⋯에서 줄 수와 표시 방식(노치에 가려진 것만 / 모두)을 그룹마다 정해요.
- **단축키 바꾸기**: 보조 키를 ⌃⌥ / ⌃⌘ / ⌥⌘ / ⌃⇧ 중에서 고르거나 끌 수 있어요.
- **언어 고르기**: 설정에서 시스템 / 한국어 / English를 골라요. 바꾼 뒤 Peeky를 다시 열면 적용돼요.
- **정보 칸**: 설정에 버전, GitHub, 변경 기록, 문제 알리기, 같은 사람이 만든 다른 앱 링크가 생겼어요.

## 바뀐 점

- **업데이트 설정**: 자동 확인(기본 켬)과 자동 설치(기본 끔)를 따로 정해요. 전에는 자동 설치가 기본으로 켜져 있었어요. 메뉴바 메뉴에도 업데이트 항목이 생겼어요.
- **업데이트 확인 강화**: 받은 파일의 서명, SHA-256, 번들 ID, 버전, 코드 서명을 모두 확인한 뒤에만 설치해요. GitHub 요청 한도에 걸리면 릴리스 페이지로 최신 버전을 알아내요.
- 그룹 밖 항목 옵션 이름을 「숨김」에서 「메뉴바에만」으로 바꿨어요.
- macOS 26 제어 센터의 크기 없는 빈 자리 항목을 목록에서 뺐어요.
- 이름이 없던 macOS 기본 항목에 배터리·Wi-Fi·소리 같은 이름이 붙어서, 설정 목록에서 알아보기 쉬워요.
- 새 그룹 아이콘이 노치에 가려지지 않도록 오른쪽 가까이에 놓아요.
- 바를 열 때 상태 아이콘이 있는 앱만 다시 확인하고, 바뀐 아이콘만 다시 캡처해서 더 가벼워요.
- 진단 로그는 설정 → 고급에서 켤 때만 남겨요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 메뉴바에서 숨기기를 켜면 처음에는 구분선 왼쪽에 있던 항목이 한꺼번에 숨겨질 수 있어요. 구분선을 누르면 펼쳐져요.

## English

Hide icons from the menu bar for real, and arrange the bar the way you like. 0.2.0 was not released separately, so its changes are listed here too.

**Installing and updating**
- On 0.1.0 with automatic installs on (the 0.1.0 default), Peeky updates itself within a day. Otherwise, download **Peeky-0.2.1.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.2.1.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- From the next version on, use **Install Version X…** in the menu bar menu or **Check Now** in Settings → Updates.

**New**
- Hide items left of a divider from the menu bar; clicking them in the bar briefly unfolds the menu bar to open their menus.
- Drag to reorder icons in the bar; **Reset Order** in Settings.
- Open the bar by hovering over the notch (off by default).
- Per-group rows and display mode.
- Choose shortcut modifiers (⌃⌥ / ⌃⌘ / ⌥⌘ / ⌃⇧) or turn shortcuts off.
- Choose the language in Settings: System / 한국어 / English (applies after reopening Peeky).
- About section in Settings: version and links to GitHub, the changelog, problem reports, and other apps.

**Changed**
- Separate switches for automatic update checks (on by default) and automatic installs (off by default; it used to be on). The menu bar menu has an update item.
- Updates install only after the signature, SHA-256, bundle ID, version, and code signature are verified; the releases page is used when GitHub's rate limit is hit.
- The option for items outside groups is now called “Menu bar only”.
- Empty placeholder items from Control Center on macOS 26 are left out.
- Names for unnamed built-in macOS items (Battery, Wi-Fi, Sound…); new group icons are placed away from the notch; lighter rescans and icon captures; diagnostic log only when turned on.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
- Turning on menu bar hiding may first hide everything already left of the divider; click the divider to unfold.
