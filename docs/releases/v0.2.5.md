노치 뒤나 구분선 왼쪽으로 들어간 Peeky 아이콘을 버튼 하나로 되찾는 버전이에요.

## 설치와 업데이트

- **0.2.2 이상을 쓰고 있다면**: 설정 → 업데이트의 **지금 확인**을 누르면 바로 설치돼요. 메뉴바 아이콘이 안 보이면 응용 프로그램 폴더에서 Peeky를 한 번 더 열어 설정 창을 띄우세요. 자동 설치가 켜져 있으면 Peeky를 쓰지 않을 때 알아서 바꿔 넣어요.
- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면 하루 안에 저절로 업데이트돼요. 아니면 아래 **Peeky-0.2.5.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.2.5.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 새 기능

- **Peeky 아이콘을 오른쪽 끝으로 옮기기**: 설정 → 메뉴바 정리에 버튼이 생겼어요. 누르면 Peeky 그룹 아이콘과 구분선(╱), ‹ / › 버튼을 메뉴바 오른쪽 끝 가까이 처음 자리로 되돌려요. 그룹 아이콘이 구분선 오른쪽에 오도록 순서도 맞춰요.
- 아이콘이 가려졌다는 안내와, 숨기기를 막았다는 안내 창에서도 같은 버튼을 바로 누를 수 있어요.
- 터미널에서는 `open -a Peeky --args --reset-icons`로도 되돌릴 수 있어요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 메뉴바에 자리가 아주 적으면 오른쪽 끝으로 옮겨도 다른 아이콘을 정리해야 보일 수 있어요.

## English

Get the Peeky icons back from behind the notch or the divider with one button.

**Installing and updating**
- On 0.2.2 or later: click **Check Now** in Settings → Updates and it installs right away. If you can't see the menu bar icon, open Peeky again from Applications to bring up the settings window. With automatic installs on, Peeky swaps itself in when you're not using it.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.2.5.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.2.5.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**New**
- **Move Peeky icons to the right end**: a new button in Settings → Menu bar cleanup puts the Peeky group icons, the divider (╱) and the ‹ / › button back near the right end of the menu bar, with the group icons to the right of the divider.
- The same button is offered in the hidden-icon notice and in the alert shown when hiding was blocked.
- From Terminal: `open -a Peeky --args --reset-icons`.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
- With very little room in the menu bar, you may still need to tidy other icons for Peeky's to show.
