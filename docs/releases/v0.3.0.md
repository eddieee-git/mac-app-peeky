아이콘마다 「보이기 / 숨기기」만 고르면 Peeky가 메뉴바를 알아서 정리하는 버전이에요. 설정과 메뉴도 훨씬 단순해졌어요.

## 설치와 업데이트

- **0.2.2 이상을 쓰고 있다면**: 설정 → 업데이트의 **지금 확인**을 누르면 바로 설치돼요. 메뉴바 아이콘이 안 보이면 응용 프로그램 폴더에서 Peeky를 한 번 더 열어 설정 창을 띄우세요. 자동 설치가 켜져 있으면 Peeky를 쓰지 않을 때 알아서 바꿔 넣어요.
- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면 하루 안에 저절로 업데이트돼요. 아니면 아래 **Peeky-0.3.0.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.3.0.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 업데이트한 뒤 설정 → 기본 설정 → **메뉴바 아이콘**에서 아이콘마다 「보이기 / 숨기기」를 한 번 확인해 주세요.

## 새 기능

- **보이기 / 숨기기만 고르면 자동 정리**: 설정 → 기본 설정 → 메뉴바 아이콘에서 아이콘마다 「보이기」나 「숨기기」(그룹이 여럿이면 「숨기기 · 그룹」)를 골라요. **「숨기기」 아이콘을 메뉴바에서 숨기기**를 켜면 Peeky가 ⌘로 끌어 옮기듯 아이콘 자리를 바꿔요. 정리하는 동안 마우스가 잠깐 움직여요. 고른 것을 바꾸면 알아서 다시 정리해요.
- **› 버튼 하나로**: 메뉴바에는 **‹ ›** 버튼만 보여요. › 오른쪽 아이콘은 늘 보이고, 왼쪽 아이콘은 숨겨져요.
- **안 보이는 이유 표시**: 아이콘 옆에 「노치 뒤」「숨겨 둠」「자리 없음」으로 지금 메뉴바에서 안 보이는 이유를 알려 줘요. 시계와 제어 센터는 「항상 보임」이에요.

## 바뀐 점

- 설정 창을 **기본 설정**과 **고급** 탭으로 나눴어요. 자주 쓰는 것은 기본 설정에 모았어요.
- 오른쪽 클릭 메뉴를 줄였어요: 바 열기, 숨긴 아이콘 보이기/다시 숨기기, 설정, (새 버전이 있을 때) 업데이트, 종료.
- 「노치에 가려진 항목만 표시」와 「노치에 마우스를 올리면 바 열기」를 뺐어요. 이제 바에는 「숨기기」 아이콘만 들어가요.
- 「바 표시」를 「Peeky 바 모양」으로 바꿨어요.
- Cloudflare One처럼 이름 뒤에 연결 상태를 덧붙이는 앱과 입력 소스 아이콘을, 상태가 바뀌어도 같은 아이콘으로 알아봐요. 고른 설정이 저절로 풀리던 문제를 고쳤어요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 노치 뒤에 있어 마우스로 잡을 수 없는 아이콘은 옮기지 못해요. 다른 아이콘을 정리해 자리가 생기면 다음 정리 때 옮겨요.
- 「보이기」 아이콘이 너무 많으면 그중 왼쪽 것은 노치에 가려질 수 있어요. Peeky 바에서는 그대로 누를 수 있어요.

## English

Just choose “Show” or “Hide” for each icon and Peeky arranges the menu bar for you. Settings and menus are much simpler too.

**Installing and updating**
- On 0.2.2 or later: click **Check Now** in Settings → Updates and it installs right away. If you can't see the menu bar icon, open Peeky again from Applications to bring up the settings window. With automatic installs on, Peeky swaps itself in when you're not using it.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.3.0.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.3.0.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- After updating, check “Show / Hide” for each icon once in Settings → General → **Menu bar icons**.

**New**
- **Choose Show or Hide, Peeky arranges**: in Settings → General → Menu bar icons, choose “Show” or “Hide” (“Hide · group” with several groups) for each icon. Turn on **Hide “Hide” icons from the menu bar** and Peeky moves the icons like a ⌘-drag. The pointer moves briefly while it does. Change a choice and Peeky arranges again.
- **One › button**: only a **‹ ›** button appears in the menu bar. Icons to its right always show; icons to its left are hidden.
- **Why it's not visible**: labels “Behind notch”, “Hidden” and “No room” tell you why an icon isn't in the menu bar right now. The clock and Control Center are “Always shown”.

**Changes**
- Settings are split into **General** and **Advanced** tabs, with the everyday options in General.
- A shorter right-click menu: open the bar, show/hide hidden icons, settings, update (when available), quit.
- Removed “Only items hidden by the notch” and “Open the bar when hovering over the notch”. The bar now holds only “Hide” icons.
- “Bar” settings are now called “Peeky bar”.
- Apps that append a connection status to their name (such as Cloudflare One) and the input source icon are recognized as the same icon when that status changes, so your choice no longer resets by itself.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
- Icons behind the notch can't be grabbed, so Peeky can't move them. Once there's room, the next arrangement moves them.
- With too many “Show” icons, the leftmost ones may be covered by the notch. You can still click them in the Peeky bar.
