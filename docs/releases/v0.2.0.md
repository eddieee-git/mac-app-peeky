메뉴바에서 아이콘을 진짜로 숨길 수 있게 되고, 바를 내 마음대로 정리하기 쉬워진 버전이에요.

## 설치와 업데이트

- **0.1.0을 쓰고 있다면**: 하루 안에 자동으로 업데이트돼요. 바로 받으려면 설정 → 업데이트 → **지금 확인**을 누르세요.
- **처음 설치한다면**: 아래 **Peeky-0.2.0.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 새 기능

- **메뉴바에서 숨기기**: 설정 → 메뉴바 정리에서 켜면 구분선(╱)이 생겨요. ⌘를 누른 채 아이콘을 구분선 왼쪽으로 옮기면 메뉴바에서 사라지고 Peeky 바에서만 보여요. 바에서 누르면 잠깐 펼쳐서 메뉴를 열고, 닫으면 다시 숨겨요.
- **끌어서 순서 바꾸기**: 바 안의 아이콘을 끌어 원하는 순서로 놓아요. 설정의 **순서 초기화**로 되돌려요.
- **노치에 마우스 올리기**: 켜 두면 노치에 마우스를 잠깐 올리기만 해도 첫 그룹 바가 열려요.
- **그룹마다 따로**: 그룹 옆 ⋯에서 줄 수와 표시 방식(노치에 가려진 것만 / 모두)을 그룹마다 정해요.
- **단축키 바꾸기**: 보조 키를 ⌃⌥ / ⌃⌘ / ⌥⌘ / ⌃⇧ 중에서 고르거나 끌 수 있어요.

## 바뀐 점

- 이름이 없던 macOS 기본 항목에 배터리·Wi-Fi·소리 같은 이름이 붙어서, 설정 목록에서 알아보기 쉬워요.
- 새 그룹 아이콘이 노치 쪽에 생겨 가려지지 않도록 오른쪽 가까이에 놓아요.
- 시스템 언어가 한국어가 아니면 영어로 보여요.
- 바를 열 때 상태 아이콘이 있는 앱만 다시 확인하고, 바뀐 아이콘만 다시 캡처해서 더 가벼워요.
- 진단 로그는 설정 → 고급에서 켤 때만 남겨요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 메뉴바에서 숨기기를 켜면 처음에는 구분선 왼쪽에 있던 항목이 한꺼번에 숨겨질 수 있어요. 구분선을 누르면 펼쳐져요.

## English

Hide icons from the menu bar for real, and arrange the bar the way you like.

- **Update**: 0.1.0 updates itself within a day (settings → Updates → **Check now** to get it right away). New installs: download **Peeky-0.2.0.dmg** and drag Peeky into Applications.
- **New**: hide items left of a divider from the menu bar (clicking them in the bar briefly unfolds the menu bar); drag to reorder icons in the bar; open the bar by hovering over the notch; per-group rows and display; choose shortcut modifiers or turn them off.
- **Changed**: names for unnamed built-in macOS items (Battery, Wi-Fi, Sound…); new group icons are placed away from the notch; English interface when the system language isn't Korean; lighter rescans and icon captures; diagnostic log only when turned on.
- **Known limitations**: Apple silicon and macOS 14+ only; unsigned by Apple, so the first launch shows a warning; turning on menu bar hiding may first hide everything already left of the divider — click the divider to unfold.
