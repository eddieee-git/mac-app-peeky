자동 정리를 더 안전하게 바꾸고, 새로 설치한 앱의 아이콘은 메뉴바에 보이게 한 버전이에요.

## 설치와 업데이트

- **0.2.2 이상을 쓰고 있다면**: 설정 → 업데이트의 **지금 확인**을 누르면 바로 설치돼요. 자동 설치가 켜져 있으면 Peeky를 쓰지 않을 때 알아서 바꿔 넣어요.
- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면 하루 안에 저절로 업데이트돼요. 아니면 아래 **Peeky-0.3.3.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.3.3.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 업데이트해도 지금 고른 「보이기 / 숨기기」는 그대로예요.

## 새 기능

- **새 아이콘은 「보이기」**: 새로 설치한 앱의 아이콘은 메뉴바에 보이는 쪽(› 오른쪽)으로 자리를 잡아요. 숨기려면 설정에서 「숨기기」를 고르세요.
- **「옮기지 못함」 표시**: 노치 뒤에 있어 잡을 수 없었거나 끌어도 옮겨지지 않은 아이콘에 표시가 붙어요.

## 바뀐 점

- 자동 정리를 안전하게 바꿨어요. 메뉴바가 안 보일 때(전체 화면 앱 등)는 정리하지 않아요. 정리하는 중에 마우스를 누르거나 움직이면 멈췄다가 잠시 뒤 다시 해요.
- 옮긴 아이콘이 메뉴바에서 사라지면 정리를 멈추고 알려 줘요.
- Peeky 바에서 설정(⚙) 버튼을 뺐어요. 설정은 Peeky 아이콘 오른쪽 클릭 → **설정…**으로 열어요. 바가 비어 있을 때만 안내 옆에 남아요.
- 바의 아이콘에 마우스를 올렸을 때도 설정과 같은 말(노치 뒤 / 숨겨 둠 / 자리 없음 / 옮기지 못함)로 알려 줘요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 노치 뒤에 있어 잡을 수 없는 아이콘은 옮기지 못해요.

## English

Safer automatic arranging, and icons from newly installed apps stay visible in the menu bar.

**Installing and updating**
- On 0.2.2 or later: click **Check Now** in Settings → Updates and it installs right away. With automatic installs on, Peeky swaps itself in when you're not using it.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.3.3.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.3.3.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- Your current “Show / Hide” choices are kept.

**New**
- **New icons are “Show”**: icons from newly installed apps are placed on the visible side (right of ›). Choose “Hide” in settings to hide them.
- **“Couldn't move” label**: icons Peeky couldn't grab (behind the notch) or that didn't move are marked.

**Changes**
- Safer arranging: Peeky doesn't arrange while the menu bar is hidden (full-screen apps and so on), and pauses and retries if you press or move the mouse while it works.
- If a moved icon disappears from the menu bar, Peeky stops and tells you.
- The settings (⚙) button is gone from the Peeky bar; open settings by right-clicking the Peeky icon → **Settings…**. It only remains next to the message when the bar is empty.
- Hovering an icon in the bar uses the same labels as settings (behind notch / hidden / no room / couldn't move).

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
- Icons behind the notch can't be grabbed, so Peeky can't move them.
