배터리·Wi-Fi 같은 macOS 기본 아이콘을 바와 설정에서 알아보기 쉽게 고친 버전이에요.

## 설치와 업데이트

- **0.2.2 이상을 쓰고 있다면**: 설정 → 업데이트의 **지금 확인**을 누르면 바로 설치돼요. 자동 설치가 켜져 있으면 Peeky를 쓰지 않을 때 알아서 바꿔 넣어요.
- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면 하루 안에 저절로 업데이트돼요. 아니면 아래 **Peeky-0.3.1.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.3.1.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 바뀐 점

- 화면 기록 권한이 없을 때 배터리, Wi-Fi, 블루투스, 소리 같은 macOS 기본 아이콘이 모두 같은 「제어 센터」 앱 아이콘으로 보여 구별이 안 됐어요. 이제 각자 모양에 맞는 기호로 보여요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 메뉴바와 똑같은 실제 모양은 화면 기록 권한이 있어야 보여요.

## English

macOS built-in icons such as Battery and Wi-Fi are now easy to tell apart in the bar and in settings.

**Installing and updating**
- On 0.2.2 or later: click **Check Now** in Settings → Updates and it installs right away. With automatic installs on, Peeky swaps itself in when you're not using it.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.3.1.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.3.1.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**Changes**
- Without Screen Recording permission, built-in icons such as Battery, Wi-Fi, Bluetooth and Sound all showed the same Control Center app icon. They now each show a matching symbol.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
- The exact menu bar look needs Screen Recording permission.
