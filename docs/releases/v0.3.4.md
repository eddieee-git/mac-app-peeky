## 설치와 업데이트

- **0.2.2 이상을 쓰고 있다면**: 설정 → 업데이트의 **지금 확인**을 누르면 바로 설치돼요. 자동 설치가 켜져 있으면 Peeky를 쓰지 않을 때 알아서 바꿔 넣어요.
- **0.1.0을 쓰고 있다면**: 자동 설치를 켜 두었으면 하루 안에 저절로 업데이트돼요. 아니면 아래 **Peeky-0.3.4.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **처음 설치한다면**: 아래 **Peeky-0.3.4.dmg**를 내려받아 Peeky를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 새 기능

- **시작하기 안내**: 설정 맨 위에 세 단계(권한 허용 → 숨길 아이콘 고르기 → 숨기기 켜기)가 나오고, 한 단계씩 체크돼요. 닫으면 다시 나오지 않아요.
- **맨 오른쪽으로 옮기기**: 설정 목록에서 「보이기」 아이콘을 오른쪽 클릭 → **맨 오른쪽으로 옮기기**. 메뉴바 자리가 모자라도 그 아이콘이 가장 오래 보여요.
- **키보드로 고르기**: Peeky 바가 열려 있을 때 ← → ↑ ↓로 아이콘을 고르고 Return이나 Space로 메뉴를 열어요.

## 바뀐 점

- 알아보기 어려운 이름을 고쳤어요. 「TextInputMenuAgent 항목 1」은 **입력 소스**로, Karabiner의 「menu」는 **Karabiner-Elements**로 보여요.
- 숨긴 아이콘을 바에서 눌러 연 메뉴가 닫히면 바로 다시 숨겨요.
- 자동 정리가 빨라졌어요. 화면이 여러 개면 Peeky가 있는 메뉴바의 아이콘만 옮겨요.
- 설정 창이 열려 있을 때 하던 확인을 줄였어요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 노치 뒤에 있어 잡을 수 없는 아이콘은 옮기지 못해요.

## English

An easier start for new users, and keyboard control in the bar.

**Installing and updating**
- On 0.2.2 or later: click **Check Now** in Settings → Updates and it installs right away. With automatic installs on, Peeky swaps itself in when you're not using it.
- On 0.1.0 with automatic installs on, Peeky updates itself within a day. Otherwise, download **Peeky-0.3.4.dmg** below and replace Peeky in Applications.
- New installs: download **Peeky-0.3.4.dmg** and drag Peeky into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**New**
- **Getting started**: the top of settings shows three steps (allow permission → choose icons to hide → turn hiding on), checked off as you go. Close it and it won't come back.
- **Move to the right end**: right-click a “Show” icon in the settings list → **Move to the right end**. It stays visible longest when the menu bar runs out of room.
- **Keyboard selection**: while the Peeky bar is open, pick an icon with ← → ↑ ↓ and open its menu with Return or Space.

**Changes**
- Clearer names: “TextInputMenuAgent item 1” is now **Input Source**, and Karabiner's “menu” is **Karabiner-Elements**.
- When you open a hidden icon's menu from the bar, it hides again as soon as the menu closes.
- Faster arranging; with several displays, only icons in Peeky's menu bar are moved.
- Fewer background checks while the settings window is open.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- No Apple Developer signature, so macOS warns on first launch from the dmg.
- Icons behind the notch can't be grabbed, so Peeky can't move them.
